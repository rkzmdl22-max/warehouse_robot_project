# ADR-002: 모바일 매니퓰레이터 선정

## 결정

MVP는 TurtleBot3 Waffle Pi와 OpenMANIPULATOR-X의 공식 ROS 2 Humble/Gazebo 구성을 사용한다. 대상 물체는 최대 0.30kg이며 초기 시험 질량은 0.20kg으로 한다.

## 운용 제약

1. TurtleBot3가 완전히 정지한 상태에서만 팔을 움직인다.
2. 베이스 이동 전 팔은 stow 자세로 복귀해야 한다.
3. 파지 후 손가락 상태와 물체 상대 자세를 1초 동안 확인한다.
4. 적재 이동 속도는 초기값 0.08m/s 이하로 제한한다.
5. 질량, 폭 또는 인식 신뢰도가 한계를 벗어나면 Pick에 진입하지 않는다.

## 제외

TRON1 동적 보행과 UR5e 모바일 탑재는 MVP에서 제외하고 향후 확장으로 보존한다. 제공된 원본 3D 자산은 수정하지 않는다.
